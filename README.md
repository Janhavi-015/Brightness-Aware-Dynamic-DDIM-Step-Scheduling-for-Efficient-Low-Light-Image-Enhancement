# Brightness-Aware-Dynamic-DDIM-Step-Scheduling-for-Efficient-Low-Light-Image-Enhancement
**Brightness-Aware Dynamic DDIM Step Scheduling for LLIE** — A training-free dynamic sampler built on DLDiff that assigns DDIM steps {4,5,6} per image based on luminance percentile thresholds. Matches S=10 quality at 4.75 avg steps, achieving 40–45% inference speedup on LOLv2-real &amp; LSRW benchmarks.
